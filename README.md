# Mp3TagFree - Premium Audio Metadata Editor

**Mp3TagFree**는 대량의 오디오 파일 메타데이터(ID3 태그)를 직관적이고 효율적으로 편집하고 관리할 수 있도록 설계된 현대적인 WPF 기반 오디오 태그 에디터입니다. ModernWPF를 적용한 Windows Fluent Design 콘셉트의 UI와 강력한 태그 처리 라이브러리(TagLibSharp)를 조합하여 뛰어난 완성도와 빠른 사용성을 제공합니다.

---

## 🎨 주요 기능 및 특징

### 1. 메타데이터 편집 및 일괄 관리
* 곡 제목, 아티스트, 앨범, 발매연도, 트랙 번호, 장르, 가사 등의 다양한 태그 정보를 손쉽게 편집합니다.
* 다중 파일 선택 시, 여러 파일에 걸쳐 있는 메타데이터를 일괄적으로 일괄 수정 및 반영할 수 있습니다.
* 저장되지 않은 수정 항목은 목록에 별도 오렌지색 글머리표(`변경`)로 표시되어 한눈에 구별할 수 있습니다.

### 2. 드래그 앤 드롭 앨범 아트 관리
* 파일 업로드를 통하거나, 이미지 파일을 앨범 아트 영역으로 간단히 드래그 앤 드롭하여 파일 내 앨범 아트를 추가, 교체 및 삭제할 수 있습니다.

### 3. 패턴 기반 파일명 일괄 변경 (배치 네이밍)
* 메타데이터 필드 변수들을 자유롭게 조합하여 실제 디스크의 파일명을 일괄 변경할 수 있습니다.
* **지원 변수**: `{제목}`, `{아티스트}`, `{앨범}`, `{발매연도}`, `{장르}`, `{트랙}` (트랙은 `01`, `02` 등 2자리로 자동 포맷팅)
* **간편 삽입**: 커서 위치에 클릭 한 번으로 변수를 추가할 수 있는 둥근 알약 스타일의 간편 버튼이 탑재되어 있습니다.
* **실시간 변경 미리보기**: 패턴을 타이핑하는 순간 변경될 파일명 및 오류 여부를 실시간으로 반영하여 그리드에 표시합니다.
* **오류 방지 검증**: 유효하지 않은 특수 문자 자동 정제, 파일명 중복 충돌 방지 및 실제 파일 존재 유무 검사 등의 안전 장치를 내장하고 있습니다.

### 4. 오디오 파일 즉시 재생
* 목록 내의 오디오 항목을 **더블 클릭**하면 윈도우 기본 미디어 플레이어(VLC, Windows Media Player 등)를 실행하여 즉시 재생을 시도합니다.

### 5. 네이티브 다크 모드 및 라이트 모드 지원
* ModernWPF 테마 연동 브러시를 기반으로 제작되어 다크 테마 및 라이트 테마 전환 시 그리드 내용의 글자가 묻히지 않으며 가독성 높은 Fluent 인터페이스를 제공합니다.

## 🛠 기술 스택

* **Language**: C# 13
* **Framework**: .NET 10.0 Windows (WPF)
* **MVVM Framework**: CommunityToolkit.Mvvm (v8.4.2)
* **UI Library**: ModernWpfUI (v0.9.6)
* **Metadata Parser**: TagLibSharp (v2.3.0)

## 🚀 실행 및 빌드 방법

### 요구 사양
* .NET 10 SDK 설치가 필요합니다.

### 빌드 및 실행

1. **디렉토리 이동 및 의존성 복원**:
   ```bash
   dotnet restore
   ```
2. **프로젝트 빌드**:
   ```bash
   dotnet build
   ```
3. **애플리케이션 실행**:
   ```bash
   dotnet run
   ```

*또는 프로젝트 루트 폴더에 위치한 대화형 빌드 스크립트(`build.bat`)를 실행하여 손쉽게 빌드, 디버깅 실행 및 단일 실행 파일 릴리즈 배포 파일을 제작할 수 있습니다.*
